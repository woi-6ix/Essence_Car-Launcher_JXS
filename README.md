# Essence_Car-Launcher_JXS

Automated JXS build of Essence/OpenLauncher pinned to `f2ef3903207ef712de1cd850d8ad3b14cfadd5fc`.

Changes in this build:
- Map widget accepts validated cellular, Wi-Fi, Ethernet, or other Internet transports.
- Three horizontally swipeable home pages.
- Independent widget layouts on all three pages.
- Page 1 preserves the legacy widget layout; Pages 2 and 3 start empty.
- Widget add/remove/move/resize applies only to the current page.

The GitHub Actions workflow builds an installable debug APK artifact.
